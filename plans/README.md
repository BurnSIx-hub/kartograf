# План карты

План — короткий JSON, который говорит, какую карту построить: вид, размер, комнаты
с назначением, связи между ними, настроение, стиль и обязательные объекты. Строитель
(`src/procgen.rs`) превращает его в готовую карту: пол, стены, двери, мебель, крыши,
свет. План пишет человек, случай (окно «Процедурно» сначала сочиняет случайный план,
потом строит по нему) или языковая модель.

Открыть план: меню «Процедурно → Построить из плана…» или `kartograf.exe --plan план.json`
(с `--export папка` карта сразу уходит в Foundry). Один план с тем же `seed` даёт одну и ту же
карту. Что из задуманного не удалось, попадает в строку состояния, а ошибки плана — в окно
с перечнем по строке на каждую.

## Поля

| Поле | Что | По умолчанию |
|---|---|---|
| `version` | номер формата, сейчас `1` | обязательно |
| `kind` | `dungeon`, `cave`, `forest`, `town`, `house`, `tavern` | обязательно |
| `name` | название, только для человека | — |
| `size` | `[ширина, высота]` в клетках, 4…400 | размер открытой карты |
| `seed` | зерно случайности, любая строка | случайное при постройке |
| `mood` | `calm`, `gloomy` (темнее, тени гуще), `abandoned` (обломки, запустение) | `calm` |
| `assets` | `builtin` — встроенные ассеты; `library` — свои из паков и папки (чего там нет, берётся из встроенных; подбор по словам имени: `Bed_Wooden_A_1x2` встанет вместо кровати) | `builtin` |
| `style` | `walls`, `floor`, `roof` — имена встроенных стен, текстур и покрытий | по виду карты |
| `river` | `auto`, `none`, `north`, `east`, `south`, `west` | `auto` |
| `rooms` | список комнат, см. ниже | — |
| `links` | список связей, см. ниже | строитель соединит сам |
| `objects` | объекты вне комнат: во дворе, на площади, у стоянки | — |
| `options` | `density` 0…1, `loops` 0…1, `fill` да/нет, `room_size` `[от, до]`, у леса, дома, таверны и квартала `season`: `summer`, `spring`, `autumn`, `winter`, `magic` (или «лето», «весна», «осень», «зима», «магический»), у пещеры `cave`: `stone`, `ice`, `sand`, `swamp`, `volcanic`, `fungal` (или «каменная», «ледяная», «песчаная», «болотная», «вулканическая», «грибная») | `0.5`, `0.1`, `true`, `[5, 10]`, `summer`, `stone` |

Комната (`rooms[]`):

| Поле | Что |
|---|---|
| `id` | имя для связей, уникальное; `outside` занято — так зовётся улица |
| `name` | подпись на карте; без неё подписи нет |
| `role` | `hall`, `living`, `kitchen`, `bedroom`, `storage`, `library`, `shrine`, `armoury`, `treasure`, `barracks`, `entrance`, `exit`, `ruin`, `empty`; без роли — `auto` |
| `size` | `small`, `medium`, `large` или `[ширина, высота]` в клетках |
| `floor` | своё покрытие пола |
| `objects` | что обязательно стоит в комнате, кроме мебели по роли |

Связь (`links[]`): `from`, `to` — имена комнат или `outside`; `kind` — `door` (по умолчанию),
`double_door`, `opening`, `secret` (тайный ход: на картинке стена цельная, в редакторе пунктир,
в Foundry потайная дверь), `bridge` (вход через мост: дорожка от двери переходит реку).

Значения понимаются и по-русски: `"role": "кухня"`, `"kind": "тайный ход"`, `"mood": "мрачно"`,
`"river": "юг"`, объекты и стены — по подписи из библиотеки («Камин», «Фахверк»). В файл
программа пишет английские имена.

## Что проверяется

Ошибка, и карта не строится: неизвестный вид, роль или объект; две комнаты с одним именем;
связь с несуществующей комнатой; комната, до которой нет пути по связям от входа (если связи
между комнатами заданы); комнаты, которые не помещаются в дом или в карту; размер комнаты
меньше двух клеток; план более новой версии.

Предупреждение, карта строится: поле, которое вид карты не использует; связь между
несмежными комнатами (дверь не поставлена, но проходимость добирается другими дверьми);
объект, которому не нашлось места; мост без реки с той же стороны.

## Что берёт каждый вид

| Вид | Комнаты и связи | Стиль | Река | Объекты |
|---|---|---|---|---|
| `house`, `tavern` | да: комнаты делят дом по весам, связи — двери на общих стенах; вход — связь с `outside`, иначе зал с юга; окна сами | стены и пол; крыша не рисуется, дом показан изнутри | да, с любой стороны; `bridge` — вход через мост | во дворе у входа |
| `dungeon` | да: комнаты расставляются случайно, коридоры — по связям (без связей — к ближайшей плюс кольца); роли дают мебель, `entrance` — ворота, `exit` — лестница | стены и пол | нет | в комнате входа |
| `cave` | нет | стены и пол | нет | у стоянки |
| `forest` | нет | нет | `east`, `west`, `none` | у лагеря |
| `town` | нет | стены и крыши домов, пол площади | нет | на площади |

Все комнаты лежат на одном этаже: «подвал» — это комната с таким именем, а не этаж ниже.
Безымянная комната без роли и связей в подземелье — пожелание о числе комнат: если не
поместилась, предупреждения нет.

## Примеры

- `таверна_у_реки.json` — зал с камином, кухня, кладовая, подвал с тайным ходом в кладовую,
  комната для гостей, вход с моста через реку, во дворе колодец и телега.
- `дом_лесника.json` — дом из бута у реки с запада, горница с проёмом в кухню.
- `подземелье_культа.json` — привратная, казарма, храм, скрипторий, крипта за тайным ходом,
  спуск; мрачно.
- `лес_с_лагерем.json` — густой лес, ручей с востока, у лагеря телега и доска объявлений.
- `заброшенный_квартал.json` — каменные дома под серым сланцем, обломки, статуя на площади.
